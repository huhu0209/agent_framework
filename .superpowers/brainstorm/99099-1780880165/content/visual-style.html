💡 特点
• 零依赖，离线可打开

• 手动布局，复杂图需要调间距
• 设计决策注释可直接嵌入节点

🏷 决策点标注
tool_calls 检查：采用 ReAct 模式而非 Plan-then-Execute，因为工具调用结果需要即时反馈给 LLM
💡 特点
• 自动布局，复杂图也整齐
• 标准流程图语法（菱形判断框）
• 需要 CDN 引入 mermaid.min.js
• 设计决策需单独用标注框展示

考虑因素

HTML/CSS 方案优势

  • 与现有模版无缝融合
  • 零外部依赖，离线可用
  • 设计决策可直接嵌入节点内
  • 你已有成熟的 CSS 组件库

Mermaid.js 方案优势

  • 复杂流程自动布局更整齐
  • 标准流程图语法更专业
  • 后续添加新图只需写 mermaid 代码
  • 社区生态丰富
