    @dataclass
    class ReflectionVerdict（per D-09）：
    - satisfied: bool
    - scores: dict[str, int] = field(default_factory=dict)  # 正确性、完整性、清晰度各 1-5
    - critique: str = ""
    - @classmethod from_llm_response(cls, text: str) -> ReflectionVerdict:
      - 用 re.search(r'\{[^{}]*\}', text, re.DOTALL) 提取 JSON 块
      - 尝试 json.loads 解析
      - 成功: 返回 cls(satisfied=bool(data.get("satisfied", False)), scores=data.get("scores", {}), critique=data.get("critique", ""))
      - 失败（json.JSONDecodeError, ValueError, AttributeError）: 返回 cls(satisfied=False, scores={}, critique=f"评估失败，原始输出：{text[:200]}")

    class ReflectionAgent(Agent)（per D-10, D-11）:
    __init__ 参数：
    - adapter: ILLMAdapter
    - model: str (keyword-only)
    - router: ToolRouter (keyword-only)
    - ctx: ToolUseContext (keyword-only)
    - max_improvement_rounds: int = 2 (keyword-only, per D-11)
    - max_steps_per_round: int = 10 (keyword-only)

    run(self, user_message: str) -> AsyncGenerator[AgentEvent, None] 实现：

    核心循环（per REFL-01, D-11）：
    - current_prompt = user_message
    - global_step = 0
    - for round_num in range(self.max_improvement_rounds + 1):  # 1 执行 + 2 改进 = 3 轮
      a. 执行阶段（per D-10）：
         - 创建 AgentLoop 实例（保留工具调用能力）
         - async for event in loop.run(current_prompt):
           - global_step 递增
           - 转发 step 和 tool_result 事件（LoopEvent 是 AgentEvent 子类）
         - 收集最终输出文本

      b. 评估阶段（per D-10）：
         - 调用 self._reflect(user_message, output)
         - _reflect 实现：
           - 构造评估 prompt（per D-08 三维度：正确性/完整性/清晰度，各 1-5 分）
           - system prompt: "你是一个输出质量评估专家。请严格按照 JSON 格式回复。"
           - user prompt: 包含原始任务、执行输出，要求评估三维度并返回 JSON: {"satisfied": bool, "scores": {"correctness": N, "completeness": N, "clarity": N}, "critique": "具体改进建议"}
           - 调用 adapter.complete（不传 tools，纯文本）
           - 提取响应文本
           - 调用 ReflectionVerdict.from_llm_response(text) 解析
         - 返回 verdict

      c. 满意判定（per REFL-02）：
         - 如果 verdict.satisfied:
           - yield AgentEvent(type="done", step=global_step, data={"text": output, "verdict": {"satisfied": True, "scores": verdict.scores}})
           - return

      d. 改进准备（per REFL-04, D-11）：
         - 如果 round_num < self.max_improvement_rounds:
           - yield AgentEvent(type="step", step=global_step, data={"text": f"评估不满意，开始第{round_num + 1}次改进", "verdict": {"satisfied": False, "scores": verdict.scores, "critique": verdict.critique}})
           - 注入 critique 到下一轮 prompt（per REFL-04）：
             current_prompt = f"{user_message}\n\n[评估反馈]\n{verdict.critique}\n\n请根据以上反馈改进。"

    循环结束（达到改进上限）：
    - yield AgentEvent(type="done", step=global_step, data={"text": output, "verdict": {"satisfied": False, "scores": verdict.scores, "critique": verdict.critique, "max_rounds_reached": True}})

    辅助方法 _collect_loop_output：
    - async def _collect_loop_output(self, loop: AgentLoop, prompt: str) -> tuple[str, int]:
    - 遍历 loop.run(prompt) 事件
    - 从 done 事件提取最终文本
    - 返回 (output_text, step_count)

    辅助方法 _call_llm：
    - async def _call_llm(self, system_prompt: str, user_prompt: str) -> str
    - 构造 CompletionConfig（不传 tools）
    - 调用 self.adapter.complete(config)
    - 提取并返回 TextBlock 文本
