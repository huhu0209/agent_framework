  - GET /.well-known/agent-card 返回 200 + AgentCard JSON

  - GET /tasks/{id} 返回 200 + A2ATask JSON（当前状态）
  - GET /tasks/{id} 不存在的 id 返回 404
  - POST /tasks/{id}/cancel 将任务状态改为 CANCELED 返回 200
  - POST /tasks/{id}/cancel 已终态的任务返回 409 (conflict)
  - 不匹配的路由返回 404
  - 非 http scope 类型被忽略
  - Agent.run() 完成后任务状态变为 COMPLETED，result 为收集的文本
  - Agent.run() 抛异常时任务状态变为 FAILED，error 为异常信息
  - 并发 task store 访问受 asyncio.Lock 保护
  </behavior>

     - __init__(self, agent: Agent, agent_card_data: dict, api_key: str | None = None)：接收 Agent 实例、AgentCard 的 dict 表示、可选 api_key。内部维护 self._tasks: dict[str, A2ATask] 和 self._lock = asyncio.Lock()。api_key 暂存但本 task 不实现认证逻辑（Plan 03 添加）。
     - async __call__(self, scope, receive, send)：ASGI 入口。检查 scope["type"]=="http"，提取 method 和 path，分发到路由 handler。不匹配返回 404 JSON。
     - 路由实现（手动匹配 method + path）：
       - GET /.well-known/agent-card -> _handle_agent_card：返回 self._agent_card_data 的 JSON
       - POST /tasks -> _handle_create_task：读取 body（调用 _read_body），解析 JSON 获取 message，生成 uuid4 task_id，创建 PENDING A2ATask 存入 self._tasks，asyncio.create_task(_execute_task) 后台运行，返回 201 + A2ATask JSON
       - GET /tasks/{id} -> _handle_get_task：提取 path 中的 task_id，查找 self._tasks，存在返回 200 + A2ATask JSON，不存在返回 404
       - POST /tasks/{id}/cancel -> _handle_cancel_task：提取 task_id，检查是否终态（终态返回 409），否则更新为 CANCELED + updated_at，返回 200 + A2ATask JSON
     - async _execute_task(self, task_id, message)：更新 status 为 RUNNING，async for event in agent.run(message) 收集文本。done 事件的 data["text"] 收集到 result_parts。成功设 COMPLETED + result。异常设 FAILED + error。所有 self._tasks 写操作在 async with self._lock 内。
     - async _read_body(self, receive)：循环 receive() 直到 more_body=False，拼接 bytes 返回。
     - async _send_json(self, send, status, data)：发送 ASGI response start + body，content-type application/json。

  1. 创建 client.py，定义 A2AClient 类：
     - __init__(self, agent_card: AgentCard, api_key: str | None = None)：存储 agent_card，用 SecretStr 包装 api_key，创建 httpx.AsyncClient（base_url=agent_card.url，timeout 设置 connect=5.0/read=30.0/write=10.0/pool=120.0，headers 含 Content-Type 和可选 X-API-Key）。
     - async send_task(self, message: str) -> str：POST /tasks，body={"message": message}，raise_for_status，返回 response.json()["id"]。
     - async get_task(self, task_id: str) -> A2ATask：GET /tasks/{task_id}，raise_for_status，返回 A2ATask.model_validate(response.json())。
     - async cancel_task(self, task_id: str) -> A2ATask：POST /tasks/{task_id}/cancel，raise_for_status，返回 A2ATask.model_validate(response.json())。
     - async send_task_and_wait(self, message: str, *, poll_interval: float = 2.0, timeout: float = 300.0) -> A2ATask：先 send_task 获取 task_id，time.monotonic() 计算 deadline，循环 get_task + asyncio.sleep(poll_interval) 直到 status.is_terminal 或超时。超时返回 FAILED A2ATask（error="超时 ({timeout}s)"）。
     - register_as_tool(self, registry: ToolRegistry) -> None：创建 ToolSpec（name=f"a2a__{self._agent_card.name}"，description=agent_card.description，parameters 含 message string 参数，handler=self._handle_tool_call），调用 registry.register(spec)。
     - async _handle_tool_call(self, args: dict, ctx: ToolUseContext) -> ToolResult：try 调用 send_task_and_wait(args["message"])，成功返回 ToolResult(content=task.result or "")，失败返回 ToolResult(content=task.error or "unknown error", is_error=True)，异常返回 ToolResult(content=str(e), is_error=True)。
     - async aclose(self) -> None：关闭 httpx.AsyncClient。
     - 所有外部 HTTP 调用（send_task, get_task, cancel_task）用 try/except 包裹 httpx 异常，转化为 ToolResult(is_error=True) 或 raise 明确的 A2A 错误。
