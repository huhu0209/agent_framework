<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM output -> file_tools | Untrusted path strings from LLM tool calls cross into filesystem operations |
| MCP config -> env vars | User-supplied MCP configuration dict crosses into process environment |
| file_tools -> filesystem | Tool handlers execute file I/O with resolved paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | file_tools.py read_file/write_file | mitigate | Call safe_path() to validate paths are within workspace, reject traversal and absolute paths |
| T-02-02 | Elevation of Privilege | config.py McpServerConfig.env | mitigate | field_validator blocks sensitive env var names at config load time |
| T-02-03 | Information Disclosure | file_tools.py error messages | mitigate | Generic error messages that do not leak resolved path information |
| T-02-SC | Tampering | pip install (no new packages) | accept | Zero new packages installed this phase; all fixes use existing dependencies |
</threat_model>
