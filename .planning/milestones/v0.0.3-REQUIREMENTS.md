# Requirements: Agent Framework — v0.0.3 (ARCHIVED)

**Milestone:** v0.0.3 — Agent 可视化平台 MVP
**Status:** ✅ SHIPPED 2026-05-31
**Goal:** 端到端链路跑通 — config → spawn → event → WebSocket → canvas render

## EVNT — EventBus 事件系统

- [x] **EVNT-01**: 开发者可通过 EventBus 发布/订阅事件，使用 asyncio.Queue 实现 pub-sub 模式 ✅ (Plan 09-01)
- [x] **EVNT-02**: 开发者可订阅 EventBus 获取 asyncio.Queue，在异步循环中消费事件 ✅ (Plan 09-01)
- [x] **EVNT-03**: 开发者可取消订阅，EventBus 自动清理 Queue 引用 ✅ (Plan 09-01)
- [x] **EVNT-04**: VizEvent 数据模型包含 type/agent/payload/timestamp 字段，支持 JSON 序列化 ✅ (Plan 09-01)
- [x] **EVNT-05**: AgentRunner 包装 AgentLoop，将 LoopEvent 映射为 VizEvent 并广播到 EventBus ✅ (Plan 09-02)
- [x] **EVNT-06**: AgentRunner 事件映射覆盖 thinking/tool_call/tool_result/done/error/max_steps 状态 ✅ (Plan 09-02)
- [x] **EVNT-07**: AgentRunner yield 原始事件，不改变 AgentLoop 的外部行为 ✅ (Plan 09-02)

## WSRV — WebSocket 服务

- [x] **WSRV-01**: WebSocket 服务端订阅 EventBus，将 VizEvent 实时推送到所有连接的客户端 ✅ (Plan 09-03)
- [x] **WSRV-02**: WebSocket 连接断开时自动取消 EventBus 订阅，不泄漏 Queue ✅ (Plan 09-03)
- [x] **WSRV-03**: 客户端可通过 WebSocket 发送 start_team 控制命令 ✅ (Plan 09-03)
- [x] **WSRV-04**: 客户端可通过 WebSocket 发送 stop_team 控制命令 ✅ (Plan 09-03)
- [x] **WSRV-05**: WebSocket 服务使用 websockets 库，自带 ping/pong 心跳机制 ✅ (Plan 09-03)

## RNDR — Canvas 渲染层

- [x] **RNDR-01**: PixiJS v8 应用初始化，包含背景层/agent层/效果层三个 Container ✅ (Plan 10-01)
- [x] **RNDR-02**: 办公室场景包含 4 个固定点位（2 个工位 + 茶水间 + 门口） ✅ (Plan 10-01)
- [x] **RNDR-03**: 猫精灵使用 placeholder 几何图形（圆形+三角形耳朵），32×32 像素 ✅ (Plan 10-02)
- [x] **RNDR-04**: 猫精灵支持 3 种帧动画（站立/打字/喝水），对应 idle/thinking/tool_call 状态 ✅ (Plan 10-02)
- [x] **RNDR-05**: Agent 状态变化时，动物自动移动到对应场景点位（线性插值平滑移动） ✅ (Plan 10-03)
- [x] **RNDR-06**: 动物到达目标点位后播放对应状态帧动画 ✅ (Plan 10-03)
- [x] **RNDR-07**: Agent shutdown 时动物移动到门口并消失 ✅ (Plan 10-03)

## CNFG — React 配置面板

- [x] **CNFG-01**: 用户可通过表单创建 Agent（填写 name/role/system_prompt） ✅ (Plan 11-01)
- [x] **CNFG-02**: 用户可点击按钮启动 Team（POST /api/team/start） ✅ (Plan 11-03)
- [x] **CNFG-03**: 用户可点击按钮停止 Team（POST /api/team/stop） ✅ (Plan 11-03)
- [x] **CNFG-04**: Agent 列表展示每个 agent 的名称和当前状态灯（idle/thinking/tool_call/shutdown） ✅ (Plan 11-01)

## CONC — WebSocket 客户端连接

- [x] **CONC-01**: 前端 WebSocket 客户端连接后端，连接断开时指数退避自动重连 ✅ (Plan 11-02)
- [x] **CONC-02**: WebSocket 消息通过 reducer 统一分发到 React 状态 ✅ (Plan 11-02)
- [x] **CONC-03**: React 状态通过 ref 桥接到 PixiJS，PixiJS ticker 每帧读取最新值渲染 ✅ (Plan 11-03)
- [x] **CONC-04**: 连接状态指示器显示 WebSocket 连接状态（绿=连接/黄=重连/红=断开） ✅ (Plan 11-02)
- [x] **CONC-05**: 事件日志列表实时展示接收到的 VizEvent，按时间排序 ✅ (Plan 11-03)
