Per D-10, D-11: Add configurable token authentication to WebSocket handshake.

In ws_server.py:

1. Modify `serve_ws()` signature to accept optional `token: str | None = None`:
   ```
   async def serve_ws(bus: EventBus, host: str = "localhost", port: int = 8765, *, token: str | None = None) -> None:
   ```

2. Add auth status logging at the start of serve_ws (before the serve context):
   ```
   if token:
       logger.info("WebSocket server listening on ws://%s:%d (auth enabled)", host, port)
   else:
       logger.info("WebSocket server listening on ws://%s:%d (no auth, development mode)", host, port)
   ```

3. Pass token to the handler lambda: change to `lambda ws: _handler(ws, bus, token)`.

4. Modify `_handler()` signature to accept `token: str | None = None`.

5. Add auth check at the start of `_handler()`, BEFORE subscribing to bus:
   ```
   if token is not None:
       from urllib.parse import urlparse, parse_qs
       # websockets ServerConnection has request attribute with URI
       query = parse_qs(urlparse(ws.request.uri).query)
       client_token = query.get("token", [None])[0]
       if client_token != token:
           await ws.close(code=4001, reason="Unauthorized")
           return
   ```

