  <action>
Per D-07, D-09: Add XML boundary markers in PromptAssembler.render().

In assembler.py:

1. Add a module-level mapping from block name to XML tag name:
   ```
   _BLOCK_TAGS: dict[str, str] = {
       "SOUL": "soul",
       "AGENTS_RULES": "instructions",
       "IDENTITY": "identity",
       "USER": "user-provided",
       "SKILLS": "skills",
       "TOOL_GUIDANCE": "tool-guidance",
   }
   ```

2. Modify `render()` method — replace the current line:
   `return "\n\n".join(b.content for b in blocks if b.content)`
   with logic that wraps each block's content in its XML tag:
   ```
   parts = []
   for b in blocks:
       if not b.content:
           continue
       tag = _BLOCK_TAGS.get(b.name)
       if tag:
           parts.append(f"<{tag}>\n{b.content}\n</{tag}>")
       else:
           parts.append(b.content)
   return "\n\n".join(parts)
   ```

3. Do NOT modify `assemble()` — it returns the raw PromptBlock list as before. XML wrapping is only in `render()`.

4. Update test_prompt_assembler.py:
   - Tests checking render() output should verify XML tags are present.
   - Tests checking assemble() should be unaffected.
   - Add assertions that the output contains expected XML tags like `<identity>`, `<user-provided>`, etc.
