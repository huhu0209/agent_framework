       - EventBus.__init__(self, maxsize: int = 1000): _subscribers set + _lock asyncio.Lock + _maxsize（per D-01, D-03）
       - async subscribe() -> asyncio.Queue[dict[str, Any]]: Lock 内创建 Queue(maxsize=_maxsize) 并加入 _subscribers（per D-01, D-02）
       - async unsubscribe(q): Lock 内从 _subscribers discard q（per D-01）
       - async publish(event: dict[str, Any]): Lock 内复制 list(self._subscribers)，释放锁后遍历 snapshot，对每个 q 做有界推入（full 时 get_nowait 丢弃最旧 + put_nowait 推入，try/except QueueEmpty 包裹 get_nowait）（per D-02, D-03）
       - subscriber_count property: return len(self._subscribers)
       - 注意：publish 参数是 dict（VizEvent.model_dump() 的输出），不是 VizEvent 实例。这样 EventBus 对事件格式无依赖
