       - git_root = _find_git_root(project_root)
       - 如果 git_root 是 None 或 git_root == project_root，返回空列表
       - 从 project_root 向上收集到 git_root 的中间目录（不含 git_root 本身，含 project_root），存入 chain_dirs 列表
       - 反转 chain_dirs（从 git_root 附近到 project_root 附近，低到高优先级 per D-06）
       - 对每个目录 d，计算可读标签（使用 d 相对路径），添加 (d / "AGENTS.md", label) 到结果

         c. (self._project_dir / "AGENTS.local.md", ".agent-framework/AGENTS.local.md")
         d. self._parent_agents_chain() 的结果（从 git_root 向下到 project_root 的各层）
         e. (self._global_dir / "user.md", "~/.agent-framework/user.md")

       - 返回 "\n\n".join(parts)，空列表返回 "" (per D-08)
