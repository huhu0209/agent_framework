    **rules/__init__.py**: Barrel export with `__all__ = ["RuleLoader"]`, one-line Chinese docstring per convention. Import RuleLoader from rules.loader.

    **rules/loader.py**: Create `RuleLoader` class with a single `@staticmethod load_rules(loader: ConfigLoader, context_path: str | None = None) -> str`.

    Import from: `from fnmatch import fnmatch`, `from pathlib import Path`, `from agent_framework.config.loader import ConfigLoader`, `from agent_framework.memory.frontmatter import parse_frontmatter_lines`.

    Internal helper `_parse_rule_document(text: str) -> tuple[dict[str, str], str]`: follows the exact pattern from skills/parser.py `_parse_skill_document`. Splits on `---` delimiters, parses lines between them with `parse_frontmatter_lines`, returns (meta, body).

    Internal helper `_parse_paths(value: str | None) -> list[str] | None`: follows the exact pattern from skills/parser.py. Splits comma-separated string, strips whitespace, returns list or None.

    `load_rules` logic per D-05/D-06/D-07:
    1. Call `loader.discover("rules")` to get directory list.
    2. For each directory, iterate `sorted(rules_dir.glob("*.md"))` for deterministic order.
    3. Read file, call `_parse_rule_document`.
    4. Get `meta.get("paths")`, call `_parse_paths` on it.
    5. If `rule_paths is None` (no paths frontmatter): always append body per D-07.
    6. If `rule_paths is not None and context_path is not None`: check `any(fnmatch(context_path, p) for p in rule_paths)`. If match, append body.
    7. If `rule_paths is not None and context_path is None`: skip (scoped rule but no context provided to match against). This matches D-12 where context_path=None means no path filtering context, so scoped rules cannot be evaluated.
    8. Join collected bodies with `"\n\n".join(all_rules)`.
