    Create useWebSocket hook and ConnectionIndicator, then update AppLayout to use both.

    **hooks/useWebSocket.ts** — Export function `useWebSocket` accepting options: url (string), dispatch (React.Dispatch<AppAction>), maxRetries (number, default 10), initialDelay (number, default 1000), maxDelay (number, default 30000). Per D-08, D-09:
    - Use three refs: wsRef (WebSocket | null), retryCountRef (number), retryTimerRef (timeout handle)
    - Define `connect` callback with useCallback: clean up old connection (null out onopen/onclose/onmessage/onerror handlers, close if OPEN or CONNECTING), create new WebSocket(url), set up handlers:
      - onopen: reset retryCountRef to 0, dispatch WS_CONNECTED
      - onclose: dispatch WS_DISCONNECTED, call attemptReconnect
      - onerror: no-op (onclose fires after onerror, reconnect logic lives in onclose)
      - onmessage: JSON.parse the data string. If data.type === 'command_response', dispatch COMMAND_RESPONSE with success and error. Otherwise dispatch VIZ_EVENT with the parsed data as the event. Wrap JSON.parse in try-catch, silently ignore parse failures.
    - Define `attemptReconnect` callback with useCallback: if retryCountRef >= maxRetries, return. Calculate delay as min(initialDelay * 2^retryCount, maxDelay). Increment retryCountRef. Dispatch WS_RECONNECTING with retryCount. Set retryTimerRef to setTimeout calling connect after delay.
    - Define `sendMessage` callback with useCallback: if wsRef.current readyState is OPEN, send JSON.stringify(data).
    - useEffect: call connect on mount. Return cleanup function: clear retryTimerRef if set, set wsRef.current.onclose to null (prevent cleanup-triggered reconnect), close wsRef.current if exists.
    - Return { sendMessage } from the hook.
    - IMPORTANT: useCallback dependencies must include all referenced values. connect depends on [url, dispatch]. attemptReconnect depends on [connect, maxRetries, initialDelay, maxDelay, dispatch].
