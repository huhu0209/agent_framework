## Typography

Three sizes, two weights — scoped to this developer tool UI (not the full DESIGN.md marketing scale):

| Role | Size | Weight | Line Height | Font Family | Usage |
|------|------|--------|-------------|-------------|-------|
| Heading | 16px | 600 (semibold) | 1.3 | system-ui | Section titles in right panel ("Agent Config", "Agent Status", "Event Log") |
| Body | 14px | 400 (regular) | 1.5 | system-ui | Form labels, input text, event log entries, status text, button labels |
| Caption | 12px | 400 (regular) | 1.4 | system-ui | Connection status text, event timestamps, metadata |

Rationale: This is a control panel, not a marketing page. The DESIGN.md serif-at-64px scale is inappropriate for a compact tool UI. 14px body ensures the right panel fits dense information alongside an 800px canvas. DESIGN.md Do's/Don'ts specify generous line-height (1.5-1.6) even at small sizes, which we follow.

## Event Log Entry Format

Each entry displays on one line:

```
HH:MM:SS  [event_type]  agent_name
```

- Timestamp: `12px` Stone Gray (#87867f), formatted via `Date.toLocaleTimeString('en-GB')`
- Event type badge: `12px`, colored background per event type, `4px` border-radius, `2px 6px` padding
  - `thinking`: bg #dbeafe (light blue), text #1d4ed8
  - `tool_call`: bg #ffedd5 (light orange), text #c2410c
  - `idle`: bg #dcfce7 (light green), text #15803d
  - `done`: bg #dcfce7 (light green), text #15803d
  - `error`: bg #fef2f2 (light red), text #b53333
  - `shutdown`: bg #f3f4f6 (light gray), text #6b7280
- Agent name: `14px` Near Black (#141413), weight 400
