    Create the state management foundation as three files under frontend/src/state/:

    **state/types.ts** — Define all TypeScript types using `import type` for type-only imports (verbatimModuleSyntax). Do NOT use `enum` (erasableSyntaxOnly). Define:
    - `ConnectionStatus` union type: `'connected' | 'reconnecting' | 'disconnected'`
    - `AgentState` interface with fields: name (string), status (union `'idle' | 'thinking' | 'tool_call' | 'shutdown'`), lastEvent (VizEvent | null)
    - `AppState` interface with fields: connection ({ status: ConnectionStatus, retryCount: number }), agents (Map<string, AgentState>), eventLog (VizEvent[]), formData ({ name: string, role: string, systemPrompt: string }), isTeamRunning (boolean)
    - `AppAction` discriminated union with variants: WS_CONNECTED, WS_DISCONNECTED, WS_RECONNECTING (with retryCount), VIZ_EVENT (with event: VizEvent), COMMAND_RESPONSE (with success, error?), UPDATE_FORM (with field, value), TEAM_STARTED, TEAM_STOPPED

    **state/reducer.ts** — Pure function `appReducer(state: AppState, action: AppAction): AppState`. Import types with `import type`. Handle all action variants:
    - WS_CONNECTED: set connection.status to 'connected', retryCount to 0
    - WS_DISCONNECTED: set connection.status to 'disconnected', isTeamRunning to false
    - WS_RECONNECTING: set connection.status to 'reconnecting', connection.retryCount to action.retryCount
    - VIZ_EVENT: create new Map from state.agents, set/update the agent entry keyed by event.agent with mapped status (via helper function mapEventTypeToAgentStatus), append event to eventLog and slice to last 50 entries
    - COMMAND_RESPONSE: return state unchanged (error handling deferred)
    - UPDATE_FORM: spread formData with [action.field] dynamic key
    - TEAM_STARTED: set isTeamRunning to true
    - TEAM_STOPPED: set isTeamRunning to false
    - Export constant `initialAppState: AppState` with empty agents Map, empty eventLog, disconnected connection, empty formData, isTeamRunning false

    **state/context.tsx** — Create React context for AppState + Dispatch<AppAction>. Export `AppProvider` function component that wraps children with `useReducer(appReducer, initialAppState)` and provides both state and dispatch via context. Export `useAppState` custom hook that consumes the context and throws if used outside provider.
  </action>
