## Phase Goal

**As a** 开发者, **I want to** 看到 Terracotta 色猫精灵在办公室场景中根据 Agent 状态切换帧动画, **so that** 可以可视化反映 Agent 内部状态变化。

<objective>
实现猫精灵几何绘制（圆形身体 + 三角耳朵 + 眼睛），4 种程序化帧动画（站立、走路、打字、喝水），动画状态切换控制器。将精灵添加到场景 agent 层，在 index.ts 的 updateState 中连接状态到动画。

</objective>

            - 更新 currentAnimation = state。
