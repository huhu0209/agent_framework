    - movement.ts 导出 createMovementSystem 函数，接收 sprite Container 和 app Application
    - lerp 公式：current + (target - current) * speed * deltaTime
    - MOVE_SPEED 常量约 0.05-0.08（控制移动速度）
    - ARRIVAL_THRESHOLD 常量 = 1.0（避免 lerp 永远不到达的浮点问题，per RESEARCH Pitfall 4）
    - 到达检测用 Math.hypot 距离 < ARRIVAL_THRESHOLD
    - 到达后直接设 x=targetX, y=targetY 消除残余误差
    - isMoving 属性返回当前是否在移动中
    - onArrive 回调在到达后被调用
    - dispose 清理 ticker callback
    - v8 ticker 回调签名 (ticker: Ticker) 使用 ticker.deltaTime
  </acceptance_criteria>
  <action>
    创建 frontend/src/canvas/movement.ts：

    1. 导入 Container, Application, Ticker 从 'pixi.js'。
    2. 定义常量：MOVE_SPEED = 0.06, ARRIVAL_THRESHOLD = 1.0。
    3. 导出 MovementState 接口：{ isMoving: boolean; targetX: number; targetY: number; onArrive?: () => void }。
    4. 导出 MovementSystem 接口：
       - moveTo(x: number, y: number, onArrive?: () => void): void — 设置目标位置和到达回调
       - readonly isMoving: boolean — 当前是否移动中
       - dispose(): void — 清理 ticker
    5. 导出 createMovementSystem(sprite: Container, app: Application): MovementSystem 工厂函数：
       a. 内部状态 state: MovementState = { isMoving: false, targetX: 0, targetY: 0 }。
       b. 注册 app.ticker.add 回调：
          - 如果 !state.isMoving，return。
          - const dt = ticker.deltaTime。
          - sprite.x += (state.targetX - sprite.x) * MOVE_SPEED * dt。
          - sprite.y += (state.targetY - sprite.y) * MOVE_SPEED * dt。
          - 距离检测：Math.hypot(state.targetX - sprite.x, state.targetY - sprite.y)。
          - 如果 distance < ARRIVAL_THRESHOLD：直接设 sprite.x = state.targetX, sprite.y = state.targetY，state.isMoving = false，调用 state.onArrive?.()。
       c. moveTo 方法：设置 state.targetX, state.targetY, state.onArrive, state.isMoving = true。
       d. dispose 方法：app.ticker.remove(tickerCallback)。
       e. isMoving getter：返回 state.isMoving。
    6. 注意 v8 Ticker 回调参数是 Ticker 实例（不是 number），需用 ticker.deltaTime 获取帧间时间。
  </action>
