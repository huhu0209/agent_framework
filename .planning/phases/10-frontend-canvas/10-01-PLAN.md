    1. frontend/src/canvas/renderer.ts：
       - 导入 Application, Container 从 'pixi.js'。
       - 导入 CANVAS_WIDTH, CANVAS_HEIGHT, DESIGN_COLORS 从 constants。
       - 导出 RendererResult 接口：{ app: Application, backgroundLayer: Container, agentLayer: Container, effectsLayer: Container, destroy: () => void }。
       - 导出 async createRenderer(container: HTMLElement, options?: { width?: number; height?: number }) 函数：
         a. `const app = new Application()` — v8 构造函数无参数。
         b. `await app.init({ width: options?.width ?? CANVAS_WIDTH, height: options?.height ?? CANVAS_HEIGHT, background: DESIGN_COLORS.PARCHMENT, antialias: true, resolution: window.devicePixelRatio || 1, autoDensity: true })`。
         c. `container.appendChild(app.canvas)` — v8 用 app.canvas 不是 app.view。
         d. 创建三个 Container：backgroundLayer（label='background'）、agentLayer（label='agent'）、effectsLayer（label='effects'）。
         e. `app.stage.addChild(backgroundLayer, agentLayer, effectsLayer)`。
         f. 返回 { app, backgroundLayer, agentLayer, effectsLayer, destroy }。destroy 调用 app.destroy(true)。

    2. frontend/src/canvas/scene.ts：
       - 导入 Graphics, Container 从 'pixi.js'。
       - 导入 POSITIONS, DESIGN_COLORS 从 constants。
       - 导出 drawScene(backgroundLayer: Container) 函数：
         a. 绘制地面线：一个宽矩形 y=500 区域，fill WARM_SAND 色，作为地面参考。
         b. 绘制工位 1 (desk1)：桌面用 rect().fill(WARM_SAND) + 描边 stroke({ width: 1, color: BORDER_CREAM })，椅子用 rect 或 poly 简笔。桌子大约 80x30 像素，中心在 desk1 坐标偏下。
         c. 绘制工位 2 (desk2)：同 desk1 样式，中心在 desk2 坐标偏下。
         d. 绘制茶水间 (teaRoom)：矩形柜台 + 小圆形杯子图案。中心在 teaRoom 坐标。
         e. 绘制门口 (door)：矩形门框 + 半圆门拱。中心在 door 坐标。
         f. 每个点位绘制一个小圆形标记（半径 4px，半透明 TERRACOTTA），放在点位坐标上，用于调试。
         g. 所有元素都是几何简笔画风格（D-02），使用 DESIGN_COLORS 暖色调。
       - 注意：v8 Graphics API 是 `.circle().fill()` 模式，不是 `beginFill().drawCircle().endFill()`。Graphics 是叶节点不能 addChild（v8 限制），每个场景元素独立添加到 backgroundLayer。

    3. frontend/src/canvas/index.ts：
       - 模块入口，管理内部 renderer 状态。
       - 维护模块级变量 let renderer: RendererResult | null = null。
       - 导出 async init(container: HTMLElement, options?)：调用 createRenderer(container, options)，然后 drawScene(renderer.backgroundLayer)。
       - 导出 updateState(event: VizEvent)：如果 renderer 存在，console.log('VizEvent received:', event.type, event.agent)。动画逻辑在 Plan 10-02 添加。
       - 导出 destroy()：调用 renderer?.destroy()，置 renderer = null。

    4. frontend/preview.html：

       - body 样式：margin 0, flex center, min-height 100vh, background Parchment #f5f4ed。
       - 包含一个 div#canvas-container。
       - script type="module"：从 './src/canvas/index.ts' 导入 init, updateState, destroy。
       - await init(container)。
       - 用 setTimeout 模拟事件序列：0ms idle, 2s thinking, 4s tool_call, 6s idle, 8s shutdown。
       - 添加一个简单的控制面板（HTML buttons）手动触发各状态。
       - 注意：preview.html 必须通过 `cd frontend && npm run dev` 访问 http://localhost:5173/preview.html，不能直接 file:// 打开。
