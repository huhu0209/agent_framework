### Task 1: 虚拟列表 auto-scroll (FT-LOGIC-03)

**Files:** `frontend/src/components/MessageList.tsx`

实现智能 auto-scroll：底部附近（100px 阈值）自动滚动到新消息，用户上滚后禁用。

1. 更新 import：添加 `useState`, `useEffect` 到 `import { useRef, useCallback } from 'react'`
2. 添加 state 追踪用户是否在底部：
   ```typescript
   const [isAtBottom, setIsAtBottom] = useState(true)
   ```
2. 修改 `handleScroll` 回调，添加底部判断：
   ```typescript
   const handleScroll = useCallback(() => {
     const el = parentRef.current
     if (!el) return

     // 底部检测
     const distanceFromBottom = el.scrollHeight - el.scrollTop - el.clientHeight
     setIsAtBottom(distanceFromBottom < 100)

     // 顶部加载更多
     if (el.scrollTop < 100 && hasMore && !loadingOlder) {
       loadOlderMessages()
     }
   }, [hasMore, loadingOlder, loadOlderMessages])
   ```
3. 添加 `useEffect` 监听新消息到达时自动滚动：
   ```typescript
   useEffect(() => {
     if (!isAtBottom) return
     const count = allItems.length
     if (count === 0) return
     virtualizer.scrollToIndex(count - 1, { align: 'end' })
   }, [allItems.length, isAtBottom, virtualizer])
   ```
4. 初始加载/会话切换时也触发滚动到底部（当 switchingSession 从 true 变 false 时）：
   ```typescript
   useEffect(() => {
     if (switchingSession) return
     // 切换会话后滚动到底部
     requestAnimationFrame(() => {
       if (allItems.length > 0) {
         virtualizer.scrollToIndex(allItems.length - 1, { align: 'end' })
       }
     })
   }, [switchingSession])  // 仅在 switchingSession 变化时触发
   ```

**Verify:** `npm run build` 通过，手动验证新消息自动滚动、上滚后停止自动滚动

### Task 3: 内联 hover 样式替换为 Tailwind (FT-ARCH-05)

**Files:** `frontend/src/components/SessionSidebar.tsx`, `frontend/src/components/SidebarToggle.tsx`

替换所有 `onMouseEnter/onMouseLeave` 内联样式操作为 Tailwind `hover:` utility classes。

**SessionSidebar.tsx — SessionItem 组件：**

1. SessionItem 外层 div：移除 `onMouseEnter/onMouseLeave`。由于 active 状态背景色 `var(--bg-ivory)` 与 hover 背景色相同，Tailwind hover 不会产生视觉差异。具体做法：
   - 保留现有 `style={{ backgroundColor: isActive ? 'var(--bg-ivory)' : 'transparent', ... }}`
   - 移除 `onMouseEnter` 和 `onMouseLeave` 中对 `backgroundColor` 的操作
   - 添加 `className` 中的 `hover:bg-[var(--bg-ivory)]` — 对 active 项无效（背景已是 ivy），对非 active 项生效
2. 编辑按钮：移除 `onMouseEnter/onMouseLeave`，添加 `hover:text-[var(--text-secondary)]`
3. 删除按钮：移除 `onMouseEnter/onMouseLeave`，添加 `hover:text-[#b53333]`

**SessionSidebar.tsx — SessionSidebar 组件：**

4. "新建会话" 按钮：移除 `onMouseEnter/onMouseLeave`，添加 `hover:bg-[var(--border-warm)]`

**SidebarToggle.tsx：**

5. 外层 button：移除 `onMouseEnter/onMouseLeave` 和 `style={{ backgroundColor: 'transparent' }}`，添加 `hover:bg-[var(--surface-sand)]` class

**Verify:** `npm run build` 通过，手动验证 hover 效果不变
