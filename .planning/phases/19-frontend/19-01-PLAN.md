### Task 4: toFrontendBlocks 类型安全 (FT-ARCH-01)

**Files:** `frontend/src/store.ts`

1. 修改 `toFrontendBlocks` 中的不安全类型断言：
   - `b.type as string` → `typeof b.type === 'string' ? b.type : ''`，空字符串走 fallback
   - `b.text as string` → `(typeof b.text === 'string' ? b.text : '')`
   - `b.name as string` → `(typeof b.name === 'string' ? b.name : '')`

### Task 6: groupBlocks orphan tool_result 处理 (FT-ARCH-04)

**Files:** `frontend/src/components/AgentResponse.tsx`

1. 修改 `groupBlocks` 函数处理孤立的 tool_result：
   - 当前逻辑只向后看一个位置找 tool_result 配对 tool_call
   - 添加逻辑：遍历时遇到 `tool_result`，如果它没被标记为已 paired，则作为独立 block 推入
   ```typescript
   function groupBlocks(blocks: AgentBlock[]) {
     const grouped: { block: AgentBlock; result?: AgentBlock }[] = []
     const paired = new Set<string>()

     for (let i = 0; i < blocks.length; i++) {
       if (paired.has(blocks[i].id)) continue

       if (blocks[i].kind === 'tool_call') {
         // 向后搜索匹配的 tool_result（最多看 5 个位置）
         let result: AgentBlock | undefined
         for (let j = i + 1; j < Math.min(i + 6, blocks.length); j++) {
           if (blocks[j].kind === 'tool_result' && !paired.has(blocks[j].id)) {
             result = blocks[j]
             paired.add(result.id)
             break
           }
           // 遇到另一个 tool_call 则停止搜索
           if (blocks[j].kind === 'tool_call') break
         }
         grouped.push({ block: blocks[i], result })
       } else {
         // 包括孤立的 tool_result，作为独立 block 渲染
         grouped.push({ block: blocks[i] })
       }
     }
     return grouped
   }
   ```
