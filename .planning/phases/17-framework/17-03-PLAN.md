    Per D-01 and D-04: Wire HITLManager into ToolRouter and decompose dispatch.

    Step A -- Add HITLManager to ToolRouter constructor:
    1. Add `hitl_manager: HITLManager | None = None` parameter to ToolRouter.__init__ (after degrader). Store as `self._hitl_manager`.
    2. Add TYPE_CHECKING import for HITLManager: `from agent_framework.safety.hitl import HITLManager` inside the TYPE_CHECKING block.
    3. Update derive() method to propagate hitl_manager to sub-routers.

    Step B -- Decompose dispatch into private methods (method extraction per D-03):
    Extract from the current dispatch method body into:
    - `async def _check_permission(self, name: str, args: dict) -> ToolResult | None` -- handles DENY (returns error) and ASK (HITL or fallback error). Returns None if ALLOW or no pipeline.
    - `async def _run_pre_hooks(self, call: ToolCall) -> tuple[ToolCall, ToolResult | None]` -- returns (possibly modified call, None) or (call, blocked_result).
    - `async def _execute_tool(self, name: str, call: ToolCall, ctx: ToolUseContext) -> ToolResult` -- the try/except block for mcp/builtin execution + degrader fallback.
    - `async def _run_post_hooks(self, name: str, args: dict, tool_result: ToolResult) -> ToolResult` -- post-hook processing, returns final result.

    The refactored dispatch becomes:
      1. permission_result = await self._check_permission(name, call.arguments) -- if not None, return it
      2. active_call, hook_result = await self._run_pre_hooks(call) -- if hook_result not None, return it
      3. tool_result = await self._execute_tool(name, active_call, ctx)
      4. tool_result = await self._run_post_hooks(name, active_call.arguments, tool_result)
      5. return tool_result

    Step C -- HITL integration in _check_permission:
    When PermissionDecision.ASK:
    1. If self._hitl_manager is not None:
       a. Create a PermissionRequest with request_id=uuid, tool_name, tool_input, reason, risk_level, and options (approve, approve_once, approve_session, deny).
       b. Call self._hitl_manager.create_pending(request) to get a Future.
       c. Await the Future: `response = await future`.
       d. If response.action == "deny": return ToolResult with is_error=True and denied message.
       e. If response.action starts with "approve": return None (allow execution to continue). Optionally update modified_input from response if present.
    2. If self._hitl_manager is None: return ToolResult with is_error=True and "needs user confirmation" message (current behavior, backward compatible).

    After extraction, run `ruff check --select C901 framework/agent_framework/tools/router.py` to verify dispatch C901 < 10. The main dispatch should be ~5-8 lines of orchestration. Each extracted method should be well under 10.
