    Per D-03 (pure method extraction) and D-04 (AgentLoop.run < 20):

    The current run() method (C901=30, lines 300-474) contains these distinct responsibility regions:
    1. Message initialization + resume logic (lines 310-319)
    2. SessionStart hook (lines 322-330)
    3. Plan initialization (lines 333-335)
    4. Main loop: notification drain (lines 341-367)
    5. Plan context injection (lines 370-382)
    6. LLM call with compaction (lines 384-395)
    7. Event yield + stop_reason branching (lines 397-472)

    Extract into private methods on AgentLoop class:
    - `def _init_messages(self, user_message: str, resume: bool) -> list[Message]` -- handles init/resume message setup. Returns the initialized message list. The caller assigns to self._messages.
    - `async def _fire_session_start_hook(self) -> None` -- fires SessionStart hook and appends inject messages to self._messages.
    - `async def _drain_notifications(self) -> None` -- drains both task_runner and team_manager notifications, appending to self._messages.
    - `def _inject_plan_context(self) -> None` -- removes old plan context and injects new one into self._messages.
    - `async def _handle_tool_calls(self, result: CompletionResult, step: int) -> AsyncGenerator[LoopEvent, None]` -- extracts tool calls from result, dispatches each via router, appends tool messages, handles plan parse and drift check. Yields tool_result events or error events. Returns None if all tool calls processed (loop continues), or yields and returns early on drift abort.

    After extraction, run() should be a clean loop:
      1. self._messages = self._init_messages(...)
      2. await self._fire_session_start_hook()
      3. plan init
      4. for step loop:
         a. await self._drain_notifications()
         b. self._inject_plan_context()
         c. try: compaction + LLM call; except: yield error, return
         d. yield step event
         e. branch on stop_reason (END_TURN -> done; MAX_TOKENS -> error; STOP_SEQUENCE -> done; TOOL_USE -> handle_tool_calls; else -> done)

    Important: The _handle_tool_calls method is the trickiest extraction because it currently contains yield statements. Since it needs to yield LoopEvents, make it an async generator that the caller iterates over:
      ```python
      async for event in self._handle_tool_calls(result, step):
          yield event
      ```
    Or alternatively, have it return a list of events and the caller yields them. Choose whichever keeps run() simpler.

    Verify with: `ruff check --select C901 framework/agent_framework/agents/agent_loop.py`
    Target: run() C901 < 20.
