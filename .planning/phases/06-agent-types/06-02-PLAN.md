    logger = logging.getLogger(__name__)

    class PlanAndSolveAgent(Agent):
        __init__ 参数（per D-04, D-06）：
        - adapter: ILLMAdapter
        - model: str (keyword-only)
        - router: ToolRouter (keyword-only)
        - ctx: ToolUseContext (keyword-only)
        - max_steps_per_plan_item: int = 10 (keyword-only)
        - max_replans: int = 2 (keyword-only, per D-05)

        run(self, user_message: str) -> AsyncGenerator[AgentEvent, None] 实现（per D-06, D-07）：

        步骤 1 — 生成计划：
        - 调用 self._generate_plan(user_message) 获取 list[PlanItem]
        - _generate_plan 实现：
          a. 构造 system prompt 指导 LLM 输出 `<plan>` 格式（复用现有 planner 的格式要求）
          b. 调用 adapter.complete() 获取 LLM 响应
          c. 提取文本，调用 parse_plan_response(text) 解析计划
          d. 返回解析结果（可能为 None 或空列表）

        步骤 2 — 空计划 fallback（per D-07, PLAN-05）：
        - 如果 plan 为 None 或空列表，yield AgentEvent(type="step", step=0, data={"text": "无法生成计划，回退到直接执行"})
        - 创建 AgentLoop 实例，async for event in loop.run(user_message) 转发事件（LoopEvent 是 AgentEvent 子类）
        - return

        步骤 3 — 逐步执行（per D-04, PLAN-03）：
        - 初始化 replan_count = 0, step_outputs = [], global_step = 0
        - 初始化 PlanningState(items=plan_items)（per D-06）
        - for item in plan_items:
          a. 构造步骤 prompt: self._build_step_prompt(user_message, item, step_outputs)
             _build_step_prompt 实现：原始任务描述 + 当前步骤描述 + 前序步骤摘要输出（截取最后 2000 字符，per D-04 Claude's Discretion）
          b. 创建独立 AgentLoop 实例：用 create_filtered_router(self.router, None) 过滤递归工具
          c. 执行 loop.run(step_prompt)，收集最终输出文本
          d. global_step 递增，yield AgentEvent(type="step", step=global_step, data={"text": 步骤描述 + 输出摘要})
          e. 将输出添加到 step_outputs
          f. 更新 PlanningState: item.status = "completed"

        步骤 4 — 偏离检测（per D-05, PLAN-04）：
        - 每步执行后调用 _detect_drift(result)
        - _rule_check_drift(result: str) -> bool | None:
          - 空输出或空白 → return True（偏离）
          - 包含 "[子代理错误]" → return True（偏离）
          - return None（规则无法判断）
        - 如果规则返回 None，调用 _llm_check_drift(user_message, item, result) 做 LLM 评估：
          - 构造简短 prompt 询问 LLM 步骤输出是否偏离了原始任务
          - 从 LLM 响应中检测 "偏离"/"off-track" 等关键词或 JSON 判断
        - 如果检测到偏离：
          - replan_count += 1
          - 如果 replan_count <= self.max_replans:
            - yield AgentEvent(type="step", step=global_step, data={"text": f"检测到偏离，重新规划 (第{replan_count}次)"})
            - 重新调用 _generate_plan 生成新计划，替换 plan_items
            - 从当前 item 之后的位置开始继续执行新计划
          - 否则:
            - yield AgentEvent(type="error", step=global_step, data={"error_message": f"偏离次数达到上限 {self.max_replans} 次"})
            - return

        步骤 5 — 完成：
        - yield AgentEvent(type="done", step=global_step, data={"text": 最终汇总输出})

        辅助方法 _collect_loop_output：
        - 辅助方法：async def _collect_loop_output(self, loop: AgentLoop, prompt: str) -> str
        - 遍历 loop.run(prompt) 的所有事件，从 done 事件中提取最终文本
        - 返回提取的文本

        辅助方法 _call_llm：
        - async def _call_llm(self, system_prompt: str, user_prompt: str) -> str
        - 构造 CompletionConfig(model=self.model, messages=[SystemMessage(content=system_prompt), UserMessage(content=[TextBlock(text=user_prompt)])])
        - 调用 self.adapter.complete(config)
        - 提取并返回文本内容
